# Revisi masukan tim PURO

Paket ini menerapkan catatan tim tanggal 18 November 2026 pada PURO Laravel. Susunan halaman dan urutan interaksi mengacu ke PURO Revisi 10 v4. **Cek status** membuka pop-up, **Konten Beranda** mengelola gambar berdasarkan jenis konten, dan **Analitik Penjualan** menampilkan filter periode, tren harian, serta perbandingan cabang. Detail pesanan staf dibuka sebagai pop-up dari dashboard. Teks aktif menggunakan hijau. FAQ ada di bawah katalog dengan tautan tepat setelah Cap & Hat Clean.

| Masukan | Lokasi dan cara memeriksa |
| --- | --- |
| 1. Keluar kembali ke login | Pilih **Keluar** dari akun staf mana pun. Halaman tujuan adalah `/staff/login`. |
| 2. Foto barang dari kurir | Saat pengantaran, kurir unggah foto serah terima dan boleh menulis titik penitipan. Setelah status **Pesanan selesai**, buka **Cek status → Foto bukti pengantaran** dengan kode pesanan. |
| 3. Tambah kategori | **Super Admin → Konten Beranda → Tambah kategori**. Kategori baru langsung tersedia di pilihan layanan dan di katalog. |
| 4. Hapus layanan | **Super Admin → Konten Beranda → Hapus layanan** pada kartu atau form edit. Layanan diarsipkan dari katalog dan pilihan booking. Pesanan lama masih memakai versi tarifnya sendiri. **Hapus gambar** menyembunyikan gambar saja dan **Contoh bawaan** mengembalikannya. |
| 5. QRIS per grup | **Super Admin → Manajemen Cabang → QRIS Cabang** menampilkan gambar dari grup terpilih. Buka **Kelola / tambah grup QRIS** untuk membuat grup baru, lalu pasangkan ke cabang yang sesuai. |
| 6. Filter akun pusat | **Super Admin → Akun Admin** menyediakan pencarian, filter cabang/peran/status, dan urutan menurut cabang/nama/peran/username. |
| 7. Lihat arsip promo | Buka **Promo Global** atau **Promo Cabang**, lalu pilih **Arsip promo**. Admin Cabang hanya bisa melihat arsip cabangnya. |
| 8. PDF pusat | **Super Admin → Analitik Penjualan → Unduh PDF**. Pilih periode WIB dan semua cabang atau satu cabang. |
| 9. Filter akun cabang | **Admin Cabang → Tim Cabang** menyediakan pencarian, filter peran/status, dan urutan nama/peran/username untuk staf operasional cabangnya. |
| 10. PDF cabang | **Admin Cabang → Analitik Penjualan → Unduh PDF**. Isi mengikuti periode dan cabang akun yang sedang masuk. |

## Memperbarui instalasi atau repo yang sudah ada

1. Buat branch kerja di repo tim. Salin kode paket ini ke folder proyek Laravel. Pertahankan `.env` yang sudah dipakai, termasuk `APP_KEY`, serta database PostgreSQL dan direktori unggahan.
2. Jalankan dari folder yang memuat `artisan`.

   ```bash
   composer install
   php artisan optimize:clear
   php artisan migrate
   php artisan puro:knowledge-sync
   ```

3. Jalankan `php artisan storage:link` bila tautan storage belum ada. Hasil build CSS dan JS sudah ikut di paket. Setelah mengedit CSS atau JS, jalankan `npm ci` dan `npm run build`.
4. Untuk memperbarui indeks Gemini setelah panduan berubah, jalankan `php artisan puro:knowledge-sync --embed` pada instalasi dengan key aktif.
5. Coba checklist tim, lalu commit perubahan dan push branch kerja ke repo tim. Instalasi baru mengikuti README.

Gunakan `php artisan migrate` pada database yang sudah berisi pesanan. `migrate:fresh` menghapus tabel dan isinya. QRIS lama tetap tersimpan pada transaksi yang sudah punya snapshot. Bukti pembayaran yang ditolak tetap dapat dikirim ulang selama pesanan belum dibatalkan.
